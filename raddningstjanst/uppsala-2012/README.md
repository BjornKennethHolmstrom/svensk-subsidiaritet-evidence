# Uppsala 2012 — K → A

Den här grenen studerar Uppsala-specifikt den kortsiktiga förändringen efter att
kommunen gick från långvarig operativ samverkan till formell pooled authority i
den gemensamma räddningsnämnden 2012.

- `publication/` — human-readable locked results and final synthesis.
- `protocols/` — estimator protocol and institutional activation/archival locks.
- `results/` — compact machine-readable estimates and diagnostics.
- `reproducibility/` — frozen runners and the inputs preserved in the source
  publication package.

## Viktigt om full rerun

Det publiceringspaket som detta repo-snapshot byggdes från innehöll inte alla
pre-match/sourcefiler som vissa frysta runners refererar till lokalt. Ingen fil
har rekonstruerats eller approximativt ersatts för att fylla luckan.

Se [`REPRODUCIBILITY.md`](REPRODUCIBILITY.md) för exakt lista. Filerna finns i
den ursprungliga lokala forskningskatalogen och kan läggas till byte-for-byte i
en senare repo-version.
