# Räddningstjänst — empiriskt evidensprogram

Den här katalogen samlar det kausala forskningsspåret om organisatorisk
arkitektur i svensk kommunal räddningstjänst.

## Två oberoende empiriska grenar

### Uppsala 2012

Frågan är den marginella effekten av att gå från etablerad operativ samverkan
(`K`) till formell pooled authority (`A`). Den frysta primära jämförelsen följs
av prespecificerade donor-, timing- och measurement-edge-kontroller.

Se [`uppsala-2012/`](uppsala-2012/).

### Historical 2002

En separat historisk kohort med fem oberoende first-full-`A` institutionella
events under Insatsrapport-96-regimen. Primärt utfall mäter brandspridning vid
räddningstjänstens ankomst.

Se [`historical-2002/`](historical-2002/).

## Gemensam syntes

De två grenarna ska inte poolas som om de estimerade exakt samma treatment eller
utfall. Deras gemensamma tolkning finns i
[`synthesis/Raddningstjanst-Cross-Branch-Causal-Synthesis-v0.1.md`](synthesis/Raddningstjanst-Cross-Branch-Causal-Synthesis-v0.1.md).
